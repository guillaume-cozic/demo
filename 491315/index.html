    Comment le paiement est branché sur votre site

    Un bouton « Réserver et payer » sur chaque atelier, la page de paiement hébergée par Stripe, et une confirmation automatique.

    1

    Le client choisit

    Atelier, date et nombre de places sur votre site. Les séances complètes ne sont plus réservables.

    2

    Stripe Checkout

    Page de paiement sécurisée Stripe (carte, Apple Pay, Google Pay), 3D Secure géré, conforme DSP2.

    3

    Webhook

    checkout.session.completed enregistre la réservation et décompte les places, sans double comptage.

    4

    Confirmation

    Page de remerciement, email au client et à vous, reçu Stripe envoyé automatiquement.

    Deux options selon votre site

    Option A — Payment Links

    Un lien de paiement Stripe par atelier, collé dans un bouton (WordPress, Wix, Squarespace, HTML…). Aucun serveur à maintenir. Idéal si le nombre de places est suivi à la main.

    Option B — Checkout + webhook

    Ce que montre cette démo : places décomptées en temps réel, séances complètes bloquées, tableau de suivi et remboursements. Petit back-end PHP / Laravel.

    Le bouton sur votre page
    <form action="/reservation/checkout" method="post">
  <input type="hidden" name="seance_id" value="42">
  <button type="submit">Réserver et payer</button>
</form>
    Création de la session de paiement (PHP / Laravel)
    $seance = Seance::findOrFail($request->seance_id);
abort_if($seance->placesRestantes() < $request->places, 409);

$session = $stripe->checkout->sessions->create([
    'mode' => 'payment',
    'customer_email' => $request->email,
    'line_items' => [[
        'price_data' => [
            'currency' => 'eur',
            'unit_amount' => $seance->atelier->prix_centimes,
            'product_data' => ['name' => $seance->libelle()],
        ],
        'quantity' => $request->places,
    ]],
    'metadata' => ['seance_id' => $seance->id],
    'success_url' => route('merci').'?session_id={CHECKOUT_SESSION_ID}',
    'cancel_url' => route('ateliers'),
]);

return redirect($session->url, 303);
    Réception du webhook
    $event = Webhook::constructEvent(
    $request->getContent(),
    $request->header('Stripe-Signature'),
    config('services.stripe.webhook_secret')
);

if ($event->type === 'checkout.session.completed') {
    Reservation::confirmerDepuisStripe($event->data->object); // idempotent
}
