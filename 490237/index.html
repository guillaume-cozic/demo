Règles du chantier

  • Maquette intouchée : aucun changement graphique ; le widget de l'assistant reprend la charte existante.
  • Aucune clé côté navigateur : l'appel au modèle passe par une route serveur (/api/chat), clé en variable d'environnement.
  • Validation serveur systématique : schémas Zod partagés, revalidés dans chaque Server Action et route API.
  • TypeScript strict, commits feat: / fix: / perf: au format Conventional Commits.
  • Référencement préservé : chaque URL qui reçoit du trafic a sa règle 301 avant la bascule.
